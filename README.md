# Unified Hotel Price Comparison Platform (UniPrice)

## Overview
UniPrice is a centralized hotel comparison platform that aggregates hotel prices from multiple booking providers such as Booking.com, Agoda, Expedia, and Hotels.com.

## Features
- Real-time hotel price comparison
- Cancellation policy transparency
- Loyalty points ROI calculator
- Historical price intelligence
- Price drop tracking alerts
- Responsive React.js interface

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- HTML5
- CSS3
- JavaScript (ES6+)

### Backend
- Node.js & Express OR FastAPI

### Database
- MongoDB
- Redis

## Architecture
Frontend → Backend API → Database / Aggregator APIs → Notification Services

## Workflow
1. User enters destination and travel dates.
2. Frontend validates input.
3. Backend fetches cached and live rates.
4. Results are displayed in hotel cards.
5. Users compare providers and track price drops.
